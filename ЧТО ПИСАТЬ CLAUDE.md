# Что писать Claude в VS Code — по этапам

Как пользоваться: открой папку `dostyq_taxi` в VS Code (File → Open Folder), открой Claude и копируй сообщения ниже по одному. Следующее — только когда предыдущее заработало на телефоне.

Если появилась ошибка — просто вставь её текст или скриншот и напиши: «Вот ошибка, исправь».

---

## Этап 1. GitHub и сборка в облаке (без установки Flutter)
```
Прочитай CLAUDE.md и папку reference, коротко перескажи проект. Я не хочу устанавливать Flutter и Android Studio. Создай приватный репозиторий dostyq-taxi на GitHub (объясни по шагам, как мне войти в GitHub), создай Flutter-проект (пакет kz.dostyq.taxi) и настрой GitHub Actions, чтобы APK собирался в облаке после каждого сохранения. Дай ссылку, где скачать APK, и объясни, как установить его на Android-телефон.
```

## Этап 2. Экраны без сервера
```
Сделай экраны клиента как в reference/app-prototype.html: главная с полем «Куда едем?», ориентиры, тарифы, оплата, кнопка «Заказать», поиск машины, машина едет, оценка. И режим водителя: «На линии», новый заказ с таймером 20 секунд, «Принять/Пропустить». Пока без сервера и без карты — данные в памяти. Стиль: шрифт Onest, зелёный #0E7C66, светлая и тёмная тема. После push дождись сборки APK в GitHub Actions и дай ссылку на скачивание.
```

## Этап 3. Настоящие заказы через Firebase
```
Подключи Firebase. Сначала напиши мне по шагам, что создать на console.firebase.google.com и куда нажать. Потом сделай: вход по номеру телефона (на время теста — тестовые номера Firebase), заказы в Firestore в реальном времени. Проверка: на одном телефоне клиент заказывает, на втором телефоне водитель видит заказ, принимает, и клиент видит «Машина едет».
```

## Этап 4. Карта и адреса
```
Добавь карту OpenStreetMap через flutter_map с центром на посёлке Достык (примерно 45.253, 82.484). Точка подачи по GPS, выбор места на карте («Указать на карте»), маршрут, машина водителя движется по его GPS. Сделай поиск адресов как в прототипе: улица и дом, ориентиры с синонимами, опечатки, латиница и английская раскладка. Нижняя панель уезжает вниз при касании карты, объекты на карте нажимаются.
```

## Этап 5. Админка и окно менеджера
```
Сделай админку по reference/admin-prototype.html как Flutter Web: роли владелец и менеджер. Для менеджера — только окно заявок: телефон, откуда, куда (с подсказками адресов и «записать как есть»), «Передать», заказ уходит ближайшему водителю. Для владельца — водители (одобрение анкет, блокировка, подписка, напоминания об оплате), адреса (улицы, ориентиры, синонимы, загрузка CSV), тарифы, аналитика и финансы.
```

## Этап 6. Межгород и доставка
```
Добавь рейсы в Ушарал: водитель создаёт рейс (дата, время, направление, 4 места), клиент выбирает места на схеме машины и бронирует. Посылки привязываются к рейсу. Доставка по посёлку: что привезти, откуда, куда.
```

## Этап 7. Запуск
```
Подготовь приложение к публикации: иконка DOSTYQ TAXI, название, push-уведомления (машина приехала, новый заказ, подписка заканчивается), сборка APK для теста и AAB для Google Play. Напиши по шагам, как опубликовать в Google Play.
```

## Полезно знать
- **Сохраняй работу**: попроси Claude «настрой git и сохрани версию» — тогда всегда можно откатиться назад.
- **Не спеши**: лучше маленький шаг, который работает, чем большой, который сломался.
- **Тест**: на каждом этапе проверяй на телефоне и с друзьями-водителями.
